# Tejas — AI + Robotics Operating System

Personal AI OS. Runs on YOUR machine.
Local-first. Voice-controlled. Free forever.

## What It Does
- Controls your PC by voice and Telegram
- Learns your habits daily  
- Routes 34+ task types to specialized agents
- Works offline — your data stays yours
- Compounds intelligence every day

## Tech Stack
- Node.js CLI
- Groq Llama 3.3 70B (primary brain)
- Gemini 2.0 Flash (backup)
- Piper TTS (voice)
- Scoring-based agent router (34/34 tests pass)

## Quick Start
npm install
tejas init
tejas run "who are you"
